# CivicLens DESIGN.md

## Product feel
High-trust municipal intelligence console: precise, premium, operational.

Do not make it look like a generic chatbot, student dashboard, crypto app, or default Tailwind template.

## Palette
- background: #07110F
- surface: #0C1714
- raised: #111F1B
- border: #20332C
- text: #F3F7F5
- muted: #91A59C
- accent: #B7FF3C
- warning: #FFC857
- danger: #FF6B6B

The lime accent is a scalpel, not paint.

## Typography
- UI: Inter/system sans
- IDs/metadata: JetBrains Mono/Consolas
- hero: 48–64px, bold, tight
- body: 14–15px
- metadata: 10–12px uppercase

## Signature components
1. Search is the hero.
2. Results always expose confidence + source count.
3. Evidence drawer explains WHY a result is trusted.
4. Ctrl+K command palette.
5. Dense intelligence rail on desktop.

## UI rules
- 14px card radius
- subtle 1px borders
- minimal shadows
- no glassmorphism overload
- no huge gradients
- no decorative animation
- confidence cannot be communicated by color alone

## Demo-video rule
Every important value proposition must be visible at 1920x1080 without scrolling through five screens.

## Agent rule
Before changing UI, read this file and preserve this visual system.
